Useful batteries.
Native speed. 🌲

The PIPI standard library is built from portable C89 modules. Each module is independent, has a declared export surface, and can be distributed as a verified .woodlib package with PIPIwood.

Included libraries

pipi/net

Blocking IPv4 TCP/UDP sockets, client and server primitives.

socketCreate · socketConnect · socketBind · socketListen · socketAccept · socketSend · socketRecv · socketClose

pipi/http

Small plain HTTP/1.0 GET helper.

httpGet(host, path, port)

pipi/fs

Text files, basic copy/move/delete and directory creation.

fileRead · fileWrite · fileAppend · fileCopy · fileMove · fileDelete

pipi/time

Unix time, millisecond timer, sleep and formatting.

timeUnix · timeMillis · sleepMs · timeFormat

pipi/string

Text inspection, replacement, case conversion and trimming.

strContains · strIndexOf · strUpper · strLower · strTrim · strReplace

pipi/encoding

URL and hexadecimal text encoding/decoding.

urlEncode · urlDecode · hexEncode · hexDecode

pipi/system

OS name, CPU architecture, environment and process info.

osName · architecture · envGet · currentDirectory · processId

pipi/crypto

SHA-256 digest and CRC32 checksum helpers.

sha256 · crc32

pipi/path

Join and inspect common filesystem paths.

pathJoin · pathBasename · pathDirname · pathExtension

pipi/json

Read JSON scalar properties from objects and escape output text.

jsonHasKey · jsonGetString · jsonGetNumber · jsonGetBoolean · jsonType · jsonEscape

pipi/random

Seedable pseudo-random integers, floats and booleans.

randomSeed · randomInt · randomFloat · randomBool

pipi/terminal

Line input, text output, ANSI colors and TTY detection.

terminalWrite · terminalWriteLine · terminalReadLine · terminalColor · terminalIsTTY

Install a library

pipiwood list dist/woodlibs/pipi_net.woodlib
pipiwood verify dist/woodlibs/pipi_net.woodlib
pipiwood install dist/woodlibs/pipi_net.woodlib

# Then in a .pipi source file:
import { socketCreate, socketConnect } from "pipi/net";

Make a .woodlib package

pipiwood pack files.lst -o acme_greeting.woodlib
pipiwood verify acme_greeting.woodlib
pipiwood install acme_greeting.woodlib

PIPIwood validates relative archive paths and checks each file's CRC32 before extraction. CRC is not a digital signature: only install native modules from publishers you trust. Full package format and third-party development guide: WOODLIB specification.

Compatibility notes

All native module sources target C89 and the stable PIPI Native Module ABI v1. Build packages for the machine architecture you intend to run on. Termux/Android ARM64 must build its own linux-aarch64 native modules; an x86-64 Linux .woodlib is not a universal binary.

HTTP is plain HTTP only (no TLS). Networking is blocking IPv4. JSON getters handle scalar members of objects; they do not materialize object/array values. Random functions are not cryptographically secure.
